# Multi-Tenant Authentication System - Complete Documentation

## Overview

A comprehensive authentication system supporting 4 distinct user roles with separate login flows, designed for a multi-tenant property management platform.

---

## Auth System Architecture

### User Roles & Access Patterns

```
┌─────────────────────────────────────────────────────────────┐
│ SUPER ADMIN                                                  │
├─────────────────────────────────────────────────────────────┤
│ URL: /superadmin/login                                      │
│ Auth Method: Email + Password                               │
│ Access: All societies, create unlimited society admins      │
│ Can: Create societies, manage all data                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ SOCIETY ADMIN                                                │
├─────────────────────────────────────────────────────────────┤
│ URL: /login                                                 │
│ Auth Method: Username + Password (generated by Super Admin) │
│ Access: Only their assigned society                         │
│ Can: Manage properties, residents, watchmen                │
│     Generate resident/watchman invitation links            │
│     Manage residents and watchmen                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ RESIDENT                                                    │
├─────────────────────────────────────────────────────────────┤
│ URL: /invite?role=resident&society=...                      │
│ Auth Method: Phone + Password (self-signup via link)       │
│ Access: Their property, visitors, parcels                   │
│ Invitation: 24-hour expiry link from Society Admin         │
│ Can: View property details, manage visitors, view parcels   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ WATCHMAN                                                    │
├─────────────────────────────────────────────────────────────┤
│ URL: /invite?role=watchman&society=...                      │
│ Auth Method: Phone + Password (self-signup via link)       │
│ Access: Society-wide visitor log, duty tracking             │
│ Invitation: 24-hour expiry link from Society Admin         │
│ Can: Log visitors, manage duty, track parcels              │
└─────────────────────────────────────────────────────────────┘
```

## Session & Security Specifications

### Session Duration
- **All Roles:** Forever (until manual logout)
- No automatic timeout
- Multi-device login allowed

### Account Lockout
- **Trigger:** 5 failed login attempts
- **Duration:** 15 minutes
- **Applies To:** All roles

### Password Requirements
- **Super Admin:** No specific requirements (backend to define)
- **Society Admin:** Generated by Super Admin
- **Resident/Watchman:** 
  - Minimum 8 characters
  - Must contain: uppercase, lowercase, number, special char (ideal)
  - Real-time strength indicator

### Invitation Links
- **Expiry:** 24 hours from generation
- **One-time Use:** No (can reuse same link if not expired)
- **Revocation:** Society Admin can revoke
- **Format:** `/invite?role={role}&society={society-id}&token={unique-token}`

### Data Security
- All screens use HTTPS placeholder (green lock badge)
- "End-to-end encrypted" messaging
- No passwords stored in localStorage (mock frontend only)
